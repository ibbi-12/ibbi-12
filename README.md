**Self-healing agentic data analyst.** Upload a CSV, ask in plain English → the agent writes Python, executes it, and **self-corrects on error (up to 4 retries)**.

- **Race Mode** — two AI coders attack the problem with different strategies; a judge agent picks the winner
- **Learning Memory** — lessons from past crashes are replayed into future runs; the agent gets measurably smarter
- **Fact-checked output** — every number is traced back to real code output, zero hallucinated figures
- **Live cockpit UI** — pipeline diagram lights up in real time as the agent moves
- **Sandboxed execution** — 30s timeout + dangerous-operation blocking

`Python` `FastAPI` `LangGraph` `Groq / Llama` `pandas` `matplotlib`
